## 源端时间校验

三段源素材都由 `scripts/record-spin-canvas-cdp.py` 以 60 fps、20 秒、1200 帧生成；录制使用无头 Chrome CDP，不依赖前台录屏窗口。逐帧遥测以红色焦点球为准：

| 事件 | 源端时间 | 处理 |
| --- | ---: | --- |
| 第一跳接触 | 0.900 s | 先停帧 0.90 s，随后逐个显示摩擦、法向和合力 |
| 第一跳讲解结束 | 1.800 s | 离开接触慢放，避免接触段吞掉后续弧线 |
| 第一跳→第二跳减速开始 | 1.817 s | 单独进入缓入的平滑减速段 |
| 减速到约 0.015× | 2.267 s | 保留整段三维飞行弧线，不让球一帧掠过 |
| 第二跳接触前慢放 | 约 2.883 s | 从第一跳弧线平滑过渡到第二次接触 |
| 第二跳接触 | 7.150 s | 再次停帧 0.90 s，显示第二次蹭台及同一组箭头逻辑 |
| 第二跳讲解结束 | 8.050 s | 平滑缓出，回到可读的出台运动 |

因此，红球第一跳到第二跳在源端占 6.25 秒；不是把一段快速录屏事后慢放，而是在 Rapier/Three.js 录制时就把中间飞行做成独立的缓入、保持和缓出。蓝球的对应接触约为 1.817 s 和 8.067 s，用于保留双球路径对照。

## 箭头方向与动画验收

箭头方向直接取自同一套台面碰撞量，不在剪辑里凭视觉猜方向：

- 绿：接触点相对台面的滑动方向 `v∥ = (contactVx, 0, contactVz)`。
- 橙：台面对球的切向摩擦，方向为 `−v∥`。
- 黄：台面的法向冲量，固定为 `+y`，即从台面向上托球。
- 紫：橙色切向摩擦与黄色法向冲量的合成方向。

箭杆固定在真实接触点；只有箭头头部沿箭杆的真实向量做循环移动，杆保持低透明度作为方向导线。这样看到的是箭头自身沿向量运动，不是整根箭头从画外飞入。第一跳和第二跳使用同一套符号与颜色，避免第二次接触时方向被误读。

## 科学口径与发布边界

视频只作条件性的三维仿真说明：不是所有下旋都会变成上旋。是否反转取决于落台时的入射速度和角度、初始旋转、切向摩擦，以及球和台面的有效接触状态。空气阻力主要使旋转衰减；重力改变落台速度和法向冲量，但不直接把下旋变成上旋。真正可能把角速度推过零的是接触瞬间的切向摩擦。RPM 是仿真计算值，有效摩擦参数不是某一张球台或胶皮的现场实测值。
