# 旋转反转专题录屏清单

> 这份旧版 90 秒清单保留作参数参考；当前 v09 实录、旁白和成片验收见 [`v09-delivery.md`](v09-delivery.md)。

这份清单面向浏览器录屏和后续轻剪，目标是制作约 90 秒的 16:9 横版母版，再裁切 9:16 竖版。仿真已经完成；录屏按钮只负责切换展示、发射双球和启动自动回放，不会写出视频文件。

## 录制前准备

1. 在项目目录运行 `npm run dev -- --host 0.0.0.0 --port 5174`，打开 `http://localhost:5174/pingpong-sim/`。
2. 使用 Chrome 全屏或无浏览器工具栏的窗口，目标画布为 1920×1080、30 fps。录制前固定窗口大小、缩放比例和浏览器主题，不要在一组镜头中改变相机位置。
3. 打开“专题演示”中的“一个球可以即是上旋球又是下旋球吗？”。蓝色轨迹是来源模型基线；红色轨迹由三个按钮选择同一台面模型下的初始旋转扫描：基线 `-3200 rpm`、临界 `-1980 rpm`、过零 `-1860 rpm`。
4. 先点“预览轨迹”采集指标镜头，再点“发射并录屏”采集干净舞台。录屏模式会隐藏面板；不要在这个模式中打开跟球面板或按 Space，Space 的功能不是暂停。
5. 默认慢放为 0.20×，自动回放红色对照球，并按勾选顺序经过跟球、裁判、上帝、观众席、端线、侧面六个视角。完整录下原始回放，成片只选最清楚的 1–2 个视角。

## 每个镜头的验收点

- 画面至少包含球、球台和网；不要用面板遮住第二跳。
- 标准、临界、高摩擦镜头中的标题必须与当前按钮状态一致。
- RPM 是模型计算值；`μ=0.25` 是来源接触模型值，不写成某个球台或胶皮的固定现场实测；空气系数表外状态必须承认是夹值。
- 录制完整自动回放后再剪辑；第二跳冻结、箭头、放大和字幕属于后期工作。
- 若某次球路被相机裁掉，重录该镜头，不用改变物理参数来“救画面”。
