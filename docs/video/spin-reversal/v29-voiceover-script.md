# v29 球友口吻旁白和字幕稿

这一版直接按球友聊天的口吻来讲：先看球怎么飞、怎么落台，再看转速怎么变。画面只保留观众需要的结果，不介绍内部实现名词。配音使用本机 Edge TTS `zh-CN-XiaoxiaoNeural` 大陆普通话女声，语速 `+8%`；没有 ChatCut 工具，也没有把这件事说成付费配音成片。

## 旁白正文

你看这个球，发出去明明是下旋。可它在台上弹两下以后，还能算下旋吗？

先看蓝球，按平常的下旋来一遍。它过网，落台两次。每次碰台以后，转得都会慢一点；第二跳以后，它还是下旋。

再看红球。我把红球出手时的下旋调小一点，球台和落点都一样。它不是一下子换方向，而是先慢慢减弱，第二跳以后几乎不转。

这次把红球起手的下旋，再调到刚好能过零。第二次落台，球擦过台面的那一下，可能把旋转继续往另一边带。你看，读数过了零，红球就显示成上旋。红球只改了起手的转速，球台和落点都没动。

看球面上的彩色分区。它是跟着球一起转的，所以你看到的是球真的在自转，不是屏幕上贴了一个方向箭头。

会不会翻过去，要看球速、入射角、起手转速，还有球和台面碰得顺不顺。空气阻力只会让球越转越慢，重力只是把球带向台面；它们不会自己把下旋变成上旋。真正可能把方向推过零的，是球落台时擦台面的切向摩擦。

所以答案是：一个球可能先是下旋，后来转得越来越慢，特定条件下还会变成上旋。但这不是所有下旋球都会发生的事。这里看到的是这组参数下的三维仿真。
