# 「一个球可以即是上旋球又是下旋球吗？」录屏与科普口径

状态：仿真专题已接入；本文是录屏执行稿和发布前的科学口径。当前录制使用 `pingpong-sim` 的真实 Three.js/Rapier 画面，并由录屏模式接管 Three.js 相机完成真实三维运镜；旁白和字幕交接包在仓库外，ChatCut 仍不可调用。

录制清单、旁白稿、字幕草稿、剪辑交接和本机验收记录见 [`docs/video/spin-reversal/`](video/spin-reversal/)，当前动态运镜交付说明见 [`v17-camera-delivery.md`](video/spin-reversal/v17-camera-delivery.md)。

## 仿真基准

- 球路：`下旋短发球`，先落发球方台面，再落接球方台面。
- 选手参考：业余俱乐部；力度 100%；关闭质量/落点波动。
- 初始上下旋：约 2304 rpm 下旋。
- 标准有效摩擦：0.25。
- 临界有效摩擦：0.465，用于展示第二跳后接近不转。
- 高有效摩擦：0.50，用于展示第二跳后过零反转。

这些数值是本项目的有效接触参数，不是对所有球、台面、胶皮和环境的材料测量。

## 必须保持的科学表述

可以说：

> 一个球在出手瞬间可以是下旋球。台面碰撞时，切向摩擦会改变球的角速度；在特定的入射速度、初始旋转和有效摩擦条件下，旋转可能过零变成上旋。

不要说：

- 重力直接把下旋变成上旋；
- 空气阻力把下旋直接拧成上旋；
- 只要是新台面、干燥环境或某种拍形就一定会反转；
- 所有下旋发球第二跳都会变成上旋；
- 仅凭对手的发球拍形就能确定球到自己这里仍是什么旋转。

更准确的因果链是：空气阻力主要使旋转衰减，马格努斯力改变飞行轨迹，重力影响落台速度和法向冲量，台面接触的切向摩擦才是改变上下旋角速度、甚至造成过零的主要环节。

## 物理审计记录

- 台面碰撞使用同一套切向接触冲量：先按球和台面的有效摩擦上限截断，再同时更新球心速度和角速度；随机冲量检查没有发现摩擦冲量增能或符号反向。
- 专题轨迹线与 Rapier 实时球现在使用同一项小幅空气旋转阻尼（每秒 0.015 的有效参数），避免画面、轨迹和 RPM 面板使用不同模型。
- 碰撞解析器对非下落输入会保留原有竖直速度，不再把防御性调用中的上升球错误归零。
- 这些改动仍是科普用有效参数，不等同于某个实测球台、球或胶皮的材料参数。

## 录屏顺序

1. 片头保留标题叠加层，提出问题：“出手时明明是下旋，第二跳以后还一定是下旋吗？”
2. 播放标准条件：标出第一跳、第二跳，字幕显示“下旋减弱，但没有反转”。
3. 播放临界条件：暂停在第二跳后，显示“接近不转”，说明这是连续变化而不是凭感觉贴标签。
4. 播放高有效摩擦条件：第二跳后显示“下旋 → 上旋”，停留一秒让观众看清过零。
5. 补充限制条件：球速、入射角、初始旋转、台面/球/胶皮的有效接触状态都会改变结果。
6. 结尾给出接球方判断：在相近来球速度、接触高度和拍面角度下，垂直反胶拍面更容易让球上蹿还是下扎，是实战判断线索；它不是旋转物理定义的唯一替代品。

## 建议旁白

“这个球出手时，确定是下旋。第一跳以后，下旋变弱了；第二跳以后，在标准条件下它还是下旋。现在把有效摩擦调到临界，旋转已经接近零。再看这一组，第二跳之后旋转过零，球在这个仿真条件下变成了上旋。

这里真正起作用的，主要是落台时的切向摩擦。空气阻力会让旋转变弱，重力会影响落台冲击，但它们不会单独把下旋拧成上旋。球速、初始旋转、落台角度，以及球台、球和胶皮的接触状态，都会改变结果。

所以不要只看对手发球时的拍形。对接球方来说，在拍面近似垂直、胶皮和接触条件相近时，更应该观察来球碰拍后是更容易上蹿还是更容易下扎。最终结论是：一个球在不同阶段可能先是下旋、后来接近不转，甚至在特定条件下变成上旋，但这不是每个球都会发生的必然规律。”

旁白时间码应在实际 AI 配音生成后重新对齐；上面的顺序是视觉锚点，不是虚构的最终音频时长。

## 发布文案

### 乒友群

一个球可以即是上旋球又是下旋球吗？

答案是：在不同阶段、不同接触条件下，可能发生。这个仿真把同一个下旋发球分别放在标准、临界和高有效摩擦条件下对照：标准条件只是减弱，临界条件接近不转，特定高摩擦条件下第二跳后可能过零变成上旋。

注意，这是条件性仿真示意，不是说所有下旋球都会反转。接球时也不要只看对方的拍形，更要看来球碰到自己拍面后的实际上蹿/下扎趋势。

建议视频下方同时展示：仿真基准、每次落台前后 RPM、有效摩擦参数、模型假设和“条件性结论”提示。小程序版本可以保留三个条件按钮，但应把“有效摩擦”标为示意参数，避免用户把它误解成某个球台或球的固定实测值。
